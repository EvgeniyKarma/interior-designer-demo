# Interior Designer Demo

Одностраничный шаблон сайта дизайнера интерьера по макетам Figma. Проект собран на HTML, CSS и JavaScript без сборщика.

## Локальный просмотр

Из корня проекта запустите:

```sh
python3 -m http.server 5173
```

Затем откройте <http://localhost:5173>.

## Адаптивность

- Десктоп: от 1200 px. Все размеры пропорционально масштабируются относительно макета 1920 px.
- Планшет: 601–1199 px. Размеры интерфейса фиксированы.
- Мобильный: до 600 px включительно. Используются мобильные значения из UI-kit.

## Содержимое

- `index.html` — секции страницы и меню;
- `styles.css` — адаптивная вёрстка и стили;
- `script.js` — меню при прокрутке и плавная навигация;
- `public/assets/` — изображения и SVG из Figma;
- `public/fonts/` — Medeo Sans.

Внешние контактные ссылки и кнопки обсуждения проекта оставлены демонстрационными.
